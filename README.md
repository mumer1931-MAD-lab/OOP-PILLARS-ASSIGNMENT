## 📁 Repository Structure & Programs

### 1. Encapsulation (Data Hiding & Validation)
Data ko protect karne aur getter/setter methods ke istemal ko demonstrate kiya gaya hai:
- `encapsulation_1.cpp` - Smart Home Thermostat (Temperature limits protection)
- `encapsulation_2.cpp` - Social Media Profile (Bio length restriction)
- `encapsulation_3.cpp` - ATM Card Security (Failed attempts & card lockout logic)
- `encapsulation_4.cpp` - Vehicle Fuel Tank (Capacity & overflow prevention)

### 2. Inheritance (Code Reusability & Hierarchy)
Base classes aur derived classes ke mukhtalif types ko implement kiya gaya hai:
- `inheritance_1.cpp` - Single Inheritance (Hospital Patient → ICU Patient)
- `inheritance_2.cpp` - Multilevel Inheritance (Spacecraft → Rocket Booster → Lunar Lander)
- `inheritance_3.cpp` - Hierarchical Inheritance (Library Resource → Book & AudioBook)
- `inheritance_4.cpp` - Multiple Inheritance (Fitness Smartwatch using Sensors & GPS)

### 3. Polymorphism (Compile-time & Run-time)
Function overloading, operator overloading aur virtual functions ka istemal:
- `polymorphism_1.cpp` - Runtime Polymorphism (Virtual functions in Document Exporter)
- `polymorphism_2.cpp` - Compile-Time Polymorphism (Function overloading for geometric volumes)
- `polymorphism_3.cpp` - Runtime Polymorphism (Notification Dispatch System - SMS & Push)
- `polymorphism_4.cpp` - Operator Overloading (2D Physics Vector Addition using `+` operator)

### 4. Abstraction (Interfaces & Pure Virtual Functions)
Implementation details hide karne aur essential features expose karne ke liye abstract classes:
- `abstraction_1.cpp` - Cloud Storage Service Interface (Pure virtual functions for upload/download)
- `abstraction_2.cpp` - Audio Codec Stream Decoder (Lossless FLAC audio interface)
- `abstraction_3.cpp` - Cryptographic Signer (RSA digital signature workflow)
- `abstraction_4.cpp` - Robotic Joint Actuator (Sensor calibration & angle control)
